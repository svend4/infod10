# Реестр источников и границы подтверждения

Здесь собраны внешние ссылки, использованные в пользовательской части сессии. Реестр нужен для навигации и последующей проверки. Он не означает, что при архивировании все страницы открывались заново, были сохранены как снимки либо подтвердили каждую формулировку прежних ответов.

Точная история того, что было сказано пользователю, сохраняется в [транскрипте](../sessions/session-001/transcript.md). Тематические документы — [Scion](scion.md) и [многоагентная вики](multi-agent-wiki.md) — различают сведения поставщика, условные примеры и проектные предложения.

Для машинной обработки доступен [указатель URL и сообщений](../sessions/session-001/links.json), автоматически извлечённый из исходной переписки.

## Как повышать доказательность при продолжении проекта

Для будущего анализа полезно сохранять снимок или закреплённую ревизию, дату доступа, подтверждающий фрагмент и связь с конкретным утверждением. Для продуктовых возможностей нужны версия и редакция. Для benchmark — окружение, настройки, набор задач и независимость измерения.

Такой сбор доказательств предлагается как следующая практика; данный архив не притворяется выполненной повторной проверкой всех источников.
