# Каталог заданий записи — session-036

Продолжение [session-035](../session-035/README.md): пояснения о неизменяемом каталоге write jobs, ограниченных страницах текущих состояний, явных строках changed и unavailable, историческом чтении без исходных путей, выполненном сценарии, независимых сверках, исправлении временного аудитора и продолжении сетевой проверки публикации версии 0.33.0, итоговый ответ, затем запрос пользователя `Продолжение`.

Сохранено **21 сообщение**: 1 пользователя и 20 ассистента, из них 19 промежуточных пояснений и 1 итоговый ответ; 6508 символов содержания. Вместе с тридцатью пятью предыдущими частями — **388 сообщений**. Идентификаторы m0001–m0021 назначены локально и относятся только к этой части.

## Границы и точность

Это ручной перенос доступного контекста беседы, а не экспорт платформы. Все включённые промежуточные сообщения, итоговый ответ и запрос пользователя непосредственно видны в доступном контексте. Содержание перенесено без исправлений. Служебные инструкции, внутренние рассуждения, сообщения субагентов и необработанные результаты инструментов в архив не входят. Автоматические контексты среды и открытой страницы не считаются сообщениями пользовательской переписки. Время отдельных сообщений недоступно; поля timestamp имеют значение null.

Граница снимка — запрос пользователя `Продолжение` после публикации версии 0.33.0 включительно. Регистр этого сообщения сохранён. Последующие анализ, разработка и ответы об этой работе в данный снимок не входят. Предыдущие части архива не изменены.

В m0020 сохранён исторический результат проверки публикации: 4512 файлов совпали с локальной копией на момент той проверки. Это не результат проверки новых файлов или последующей реализации. Указанный там коммит [75c337a0b76d9543441faf4d0840c5470c49e58e](https://github.com/svend4/infod10/commit/75c337a0b76d9543441faf4d0840c5470c49e58e) относится к версии 0.33.0 и тридцати пяти предыдущим частям архива.

В m0009–m0010 сохранены сообщение об ошибке временного аудитора и результат его повторного запуска; в m0018–m0019 — сообщение о разрыве HTTP-соединения при сетевой сверке и её продолжении. Эти исторические сообщения не исправлялись задним числом.

## Воспроизведение

Из корня репозитория:

~~~sh
python3 scripts/build_session_archive.py --session docs/sessions/session-036 --check
python3 scripts/build_session_archive.py --all --check
~~~

Для намеренной пересборки этой части уберите --check в первой команде. Скрипт не обращается в сеть. Контрольные суммы проверяют сохранённый снимок и не удостоверяют экспорт платформы.
