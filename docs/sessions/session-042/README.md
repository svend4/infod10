# Управляемая выдача guarded jobs по точной политике — session-042

Продолжение [session-041](../session-041/README.md): пояснения об отдельном издателе guarded jobs, точной политике по principal/actor/verdict/plan_id, разных ключах admin и holder и независимых отзывах, окне между сохранением guard и issuance receipt, выполнении трёх фаз после issuer revoke, восстановлении потерянного полного ответа при недоступных новых путях, независимых проверках и публикации версии 0.39.0, итоговый ответ, затем запрос пользователя `Продолжение`.

Сохранено **13 сообщений**: 1 пользователя и 12 ассистента, из них 11 промежуточных пояснений и 1 итоговый ответ; 4299 символов содержания. Вместе с сорока одной предыдущей частью — **478 сообщений**. Идентификаторы m0001–m0013 назначены локально и относятся только к этой части.

## Границы и точность

Это ручной перенос доступного контекста беседы, а не экспорт платформы. Все одиннадцать пояснений, итоговый ответ и запрос пользователя непосредственно видны в доступном контексте. Содержание перенесено без исправлений. Служебные инструкции, внутренние рассуждения, сообщения субагентов и необработанные результаты инструментов в архив не входят. Автоматические контексты среды и открытой страницы не считаются сообщениями пользовательской переписки. Время отдельных сообщений недоступно; поля timestamp имеют значение null.

Граница снимка — запрос пользователя `Продолжение` после публикации версии 0.39.0 включительно. Регистр этого сообщения сохранён. Последующие анализ, разработка и ответы об этой работе в данный снимок не входят. Предыдущие части архива не изменены.

В m0012 сохранён исторический результат проверки публикации: все 7218 файлов скачанного архива GitHub совпали с локальной копией на момент той проверки. Это не результат проверки новых файлов или последующей реализации. Указанный там коммит [220d72c37a3687f819a91739f50f0ec453f65d10](https://github.com/svend4/infod10/commit/220d72c37a3687f819a91739f50f0ec453f65d10) относится к версии 0.39.0 и сорока одной предыдущей части архива.

## Воспроизведение

Из корня репозитория:

~~~sh
python3 scripts/build_session_archive.py --session docs/sessions/session-042 --check
python3 scripts/build_session_archive.py --all --check
~~~

Для намеренной пересборки этой части уберите --check в первой команде. Скрипт не обращается в сеть. Контрольные суммы проверяют сохранённый снимок и не удостоверяют экспорт платформы.
