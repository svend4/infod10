<a id="m0002"></a>
### m0002 · Ассистент · промежуточное сообщение

Для полного комплекта выбран отдельный формат: снимок рабочей базы и каталог архивов рядом с ним. Снимок сразу получит постоянную метку карантина. После восстановления можно будет читать документы, решения и историю; новые записи и публикация останутся заблокированы.

Сначала записывается намерение создания снимка, а общий manifest — после проверки всех файлов.

<a id="m0003"></a>
### m0003 · Ассистент · промежуточное сообщение

Пример также покажет работу после снимка: действующая база перейдёт к следующей редакции, а восстановленная сохранит состояние на момент копирования.
