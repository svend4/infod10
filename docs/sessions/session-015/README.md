# Полномочия и политика принятия — session-015

Продолжение [session-014](../session-014/README.md): пояснения о локальных полномочиях и обязательной политике принятия, выполненном сценарии и публикации версии 0.12.0, итоговый ответ, затем запрос пользователя «Продолжение».

Сохранено **7 сообщений**: 1 пользователя и 6 ассистента, из них 5 промежуточных пояснений и 1 итоговый ответ. Вместе с четырнадцатью предыдущими частями — **135 сообщений**. Идентификаторы m0001–m0007 назначены локально и относятся только к этой части.

## Границы и точность

Это ручной перенос доступного контекста беседы, а не экспорт платформы. Содержание доступных сообщений сохранено без исправлений. Служебные инструкции, внутренние рассуждения, сообщения субагентов и необработанные результаты инструментов в архив не входят. Время отдельных сообщений недоступно; поля timestamp имеют значение null.

Граница снимка — запрос пользователя «Продолжение» после публикации версии 0.12.0 включительно. Последующие анализ, разработка и ответы об этой работе в данный снимок не входят. Предыдущие части архива не изменены.

В m0006 сохранён исторический результат проверки публикации: 502 файла совпали с локальной копией на момент той проверки. Это не результат проверки новых файлов или последующей реализации. Указанный там коммит [6be316b0177945a84d73b496c05c3d2e7d2d5b74](https://github.com/svend4/infod10/commit/6be316b0177945a84d73b496c05c3d2e7d2d5b74) относится к версии 0.12.0 и четырнадцати предыдущим частям архива.

## Воспроизведение

Из корня репозитория:

~~~sh
python3 scripts/build_session_archive.py --session docs/sessions/session-015 --check
python3 scripts/build_session_archive.py --all --check
~~~

Для намеренной пересборки этой части уберите --check в первой команде. Скрипт не обращается в сеть. Контрольные суммы проверяют сохранённый снимок и не удостоверяют экспорт платформы.
