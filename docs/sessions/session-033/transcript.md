<a id="m0002"></a>
### m0002 · Ассистент · промежуточное сообщение

Один план охватит до 16 выбранных позиций каталога и сохранит единый момент оценки. Это ограничит объём проверки: для каждого случая потребуется проверить свидетельства и состояние связанной попытки.

Результат будет фиксировать кандидатов для рассмотрения и причины удержания. С неизвестной исходной идентичностью, недоступными свидетельствами или незавершённой попыткой случай останется удержанным.

### m0003 · Ассистент · промежуточное сообщение

Для примера подготовлены четыре плана: с нулевым сроком, длительным сроком, отсутствующим case-каталогом и недоступной связанной попыткой. Повторное чтение должно сохранить исходную оценку после возврата путей.
