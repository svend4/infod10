# Частные снимки SQLite и историческое восстановление — session-022

Продолжение [session-021](../session-021/README.md): пояснения о согласованном снимке SQLite с WAL, карантине копий и восстановлении для исторического чтения, выполненном сценарии и публикации версии 0.19.0, итоговый ответ, затем запрос пользователя `«продолжение»`.

Сохранено **10 сообщений**: 1 пользователя и 9 ассистента, из них 8 промежуточных пояснений и 1 итоговый ответ. Вместе с двадцатью одной предыдущей частью — **206 сообщений**. Идентификаторы m0001–m0010 назначены локально и относятся только к этой части.

## Границы и точность

Это ручной перенос доступного контекста беседы, а не экспорт платформы. Содержание доступных сообщений сохранено без исправлений. Служебные инструкции, внутренние рассуждения, сообщения субагентов и необработанные результаты инструментов в архив не входят. Автоматические контексты среды и открытой страницы не считаются сообщениями пользовательской переписки. Время отдельных сообщений недоступно; поля timestamp имеют значение null.

Граница снимка — запрос пользователя `«продолжение»` после публикации версии 0.19.0 включительно. Кавычки входят в исходное содержание этого сообщения. Последующие анализ, разработка и ответы об этой работе в данный снимок не входят. Предыдущие части архива не изменены.

В m0009 сохранён исторический результат проверки публикации: 951 файл совпал с локальной копией на момент той проверки. Это не результат проверки новых файлов или последующей реализации. Указанный там коммит [73365def3ed80a02c7ba9c7ea385eb2f095e6acd](https://github.com/svend4/infod10/commit/73365def3ed80a02c7ba9c7ea385eb2f095e6acd) относится к версии 0.19.0 и двадцати одной предыдущей части архива.

## Воспроизведение

Из корня репозитория:

~~~sh
python3 scripts/build_session_archive.py --session docs/sessions/session-022 --check
python3 scripts/build_session_archive.py --all --check
~~~

Для намеренной пересборки этой части уберите --check в первой команде. Скрипт не обращается в сеть. Контрольные суммы проверяют сохранённый снимок и не удостоверяют экспорт платформы.
