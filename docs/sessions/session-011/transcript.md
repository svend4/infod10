### m0001 · Ассистент · промежуточное сообщение

Продолжу с учёта обещаний документации: какие условия уже связаны с проверяемыми обязательствами, а какие остались без рассмотрения. Проверю текущие форматы, затем добавлю ограниченный механизм покрытия и сохраню пример, в котором совпадение одного правила оставляет видимым пропущенное условие.

<a id="m0002"></a>
### m0002 · Ассистент · промежуточное сообщение

Выбрал явную опись обещаний с точными цитатами из документа. Для каждого обещания будет задано ожидаемое отношение между полем документа и константой кода.

### m0003 · Ассистент · промежуточное сообщение

Добавляю второй подсчёт — по уникальным требованиям. Он позволит увидеть разницу между двумя обещаниями, ссылающимися на одну проверку, и двумя разными условиями. После этого выполню пример и сохраню результаты.

### m0004 · Ассистент · промежуточное сообщение

## Что добавлено

Реализовано **покрытие заявленных обещаний документации**. Для каждого обещания сохраняются точная цитата и ожидаемая связь между полем документа и константой кода.

Проверка другого поля не засчитывается как покрытие. Отдельно показываются пропуски, ошибочные привязки, выполнение обязательств и устаревшие основания.

**[Подробный анализ и архитектура](https://github.com/svend4/infod10/blob/ed4b2a2dc5e7f01a20ab5947dd20fb764c437111/docs/development/promise-coverage.md)**

## Выполненный пример

**[Отчёт и сохранённые результаты](https://github.com/svend4/infod10/blob/ed4b2a2dc5e7f01a20ab5947dd20fb764c437111/examples/promise-coverage/results/report.md)**

| Ситуация | Покрытие описи | Результат |
|---|---:|---|
| Проверены методы, пропущен лимит попыток | 1 из 2 | Блокировка |
| Оба обещания правильно связаны, значения совпадают | 2 из 2 | Для рассмотрения человеком |
| Лимит связан с проверкой другого поля | 1 из 2 | Блокировка |
| Код объявляет 4 попытки вместо документированных 3 | 2 из 2 | Блокировка: `mismatch` |
| Значения совпадают, основание устарело | 2 из 2 | Блокировка: `stale_read` |

Добавлен отдельный подсчёт по уникальным требованиям: копирование одной записи не повышает эту долю.

**Граница механизма:** опись составляется явно. Полнота всей страницы и смысловая правильность выбранных связей требуют отдельного рассмотрения. Код не исполняется; внешние LLM пока не подключены.

Запуск:

```bash
python3 -m agentwiki coverage-demo \
  --workspace /tmp/agentwiki-coverage-my-run-01 \
  --workers 3
```
