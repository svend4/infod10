## Что реализовано

Добавлен устойчивый журнал, который сохраняет:

- **Неизменяемые пакеты оснований:** пару утверждений, источники, результат анализа, версии правил и политики.
- **Решения проверяющих:** поддержать, запросить изменения или воздержаться — с пояснением.
- **Историю изменения мнений:** новая запись ссылается на предыдущую, сохраняя её.
- **Безопасные повторы:** повтор идентичной операции возвращает сохранённое решение.
- **Проверку актуальности:** решение относится к точному содержимому пакета.
- **Экспорт истории:** записи связаны контрольными суммами и цепочкой событий.

## Практический сценарий

**[Отчёт выполненной демонстрации](https://github.com/svend4/infod10/blob/8ad315a0ac789be4c7805ad14a70363df1098605/examples/editorial-review/results/report.md)**

Участвовали автор пакета и три программных проверяющих. Два проверяющих отправляли решения параллельно.

| Действие | Наблюдаемый результат |
|---|---|
| Два агента поддержали пакет | `agent_agreement` |
| Третий запросил изменения | `disagreement` |
| Третий заменил своё решение | Новая запись сохранила ссылку на прежнюю |
| Повтор той же операции | Дополнительная запись не появилась |
| Указан устаревший предшественник | Отказ `decision_conflict` |
| Изменён только текст утверждения | Старый пакет получил `stale_input` |
| Создан пакет с новым текстом | `awaiting_reviews`, прежние решения не перенесены |

Сохранены **2 пакета, 4 решения и 10 событий**.

Актуальность проверяется относительно явно переданной текущей пары. Согласие агентов остаётся редакторской информацией: журнал автоматически не принимает изменения в `Store` и не публикует выпуск. Человеческое заключение в демонстрации не имитировалось.

## Как запустить

Из корня репозитория:

```bash
python3 -m agentwiki editorial-demo \
  --workspace /tmp/agentwiki-editorial-my-run-01 \
  --workers 3
```

Используйте новый пустой каталог. Отдельно доступны команды `editorial create`, `record`, `assess`, `history`, `show` и `export`.

Имена и тип участников пока самозаявленные. Контрольные суммы подтверждают внутреннюю согласованность сохранённых данных; авторство, независимость проверки и истинность содержания требуют отдельных оснований.
