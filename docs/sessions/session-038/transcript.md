<a id="m0002"></a>
### m0002 · Ассистент · промежуточное сообщение

Для безопасного повтора у каждого шага будет отдельное сохранённое намерение с точной исходной и целевой фазой. Если целевая фаза уже достигнута, повтор сможет записать наблюдение, не выполняя следующий шаг и не приписывая себе чужую работу.

Перед новым выполнением будет проверяться текущая аренда под общей блокировкой журнала. Сохранённый результат останется историческим ответом: его чтение не потребует повторного назначения.
