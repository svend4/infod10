<a id="m0002"></a>
### m0002 · Ассистент · промежуточное сообщение

Запись рассмотрения будет сохранять весь исходный план, заявленного участника и одно из решений: `reviewed`, `defer` или `request_fresh_plan`. Личность участника этим не удостоверяется.

Повторная проверка отдельно покажет состояние плана, каталога и случаев. Равенство двух ответов о недоступности не будет считаться подтверждением неизменного основания.
