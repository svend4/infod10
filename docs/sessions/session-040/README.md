# Локальный издатель permits и политика выдачи — session-040

Продолжение [session-039](../session-039/README.md): пояснения об отдельном издателе допусков, admin и holder credentials, явных правилах выдачи и immutable issuance receipts, отказе усыновлять существующий native permit, future-only отзыве издателя и историческом replay, выполненном обычном сценарии, частных и публичных сверках, публикации и побайтной проверке архива GitHub версии 0.37.0, итоговый ответ, затем запрос пользователя `Продолжение`.

Сохранено **14 сообщений**: 1 пользователя и 13 ассистента, из них 12 промежуточных пояснений и 1 итоговый ответ; 5419 символов содержания. Вместе с тридцатью девятью предыдущими частями — **449 сообщений**. Идентификаторы m0001–m0014 назначены локально и относятся только к этой части.

## Границы и точность

Это ручной перенос доступного контекста беседы, а не экспорт платформы. Все двенадцать промежуточных сообщений, итоговый ответ и запрос пользователя непосредственно видны в доступном контексте. Содержание перенесено без исправлений. Служебные инструкции, внутренние рассуждения, сообщения субагентов и необработанные результаты инструментов в архив не входят. Автоматические контексты среды и открытой страницы не считаются сообщениями пользовательской переписки. Время отдельных сообщений недоступно; поля timestamp имеют значение null.

Граница снимка — запрос пользователя `Продолжение` после публикации версии 0.37.0 включительно. Регистр этого сообщения сохранён. Последующие анализ, разработка и ответы об этой работе в данный снимок не входят. Предыдущие части архива не изменены.

В m0013 сохранён исторический результат проверки публикации: все 6244 файла скачанного архива GitHub совпали с локальной копией на момент той проверки; прямые страницы были доступны. Это не результат проверки новых файлов или последующей реализации. Указанный там коммит [c46efb4ee2260e5cb4b1b6c39a2d01811e0b592f](https://github.com/svend4/infod10/commit/c46efb4ee2260e5cb4b1b6c39a2d01811e0b592f) относится к версии 0.37.0 и тридцати девяти предыдущим частям архива.

## Воспроизведение

Из корня репозитория:

~~~sh
python3 scripts/build_session_archive.py --session docs/sessions/session-040 --check
python3 scripts/build_session_archive.py --all --check
~~~

Для намеренной пересборки этой части уберите --check в первой команде. Скрипт не обращается в сеть. Контрольные суммы проверяют сохранённый снимок и не удостоверяют экспорт платформы.
