# Полная цепочка архивов повторного переноса — session-026

Продолжение [session-025](../session-025/README.md): пояснения о сохранении всех предковых архивов в новом назначении, совместимости частных форматов, запрете credentials прежних поколений, повторном переносе и новой работе агентов, временной недоступности прежних путей, выполненном сценарии и публикации версии 0.23.0, итоговый ответ, затем запрос пользователя `Продолжение`.

Сохранено **11 сообщений**: 1 пользователя и 10 ассистента, из них 9 промежуточных пояснений и 1 итоговый ответ. Вместе с двадцатью пятью предыдущими частями — **245 сообщений**. Идентификаторы m0001–m0011 назначены локально и относятся только к этой части.

## Границы и точность

Это ручной перенос доступного контекста беседы, а не экспорт платформы. Содержание доступных сообщений сохранено без исправлений. Служебные инструкции, внутренние рассуждения, сообщения субагентов и необработанные результаты инструментов в архив не входят. Автоматические контексты среды и открытой страницы не считаются сообщениями пользовательской переписки. Время отдельных сообщений недоступно; поля timestamp имеют значение null.

Граница снимка — запрос пользователя `Продолжение` после публикации версии 0.23.0 включительно. Последующие анализ, разработка и ответы об этой работе в данный снимок не входят. Предыдущие части архива не изменены.

В m0010 сохранён исторический результат проверки публикации: 1467 файлов совпали с локальной копией на момент той проверки. Это не результат проверки новых файлов или последующей реализации. Указанный там коммит [c319e43f57da289ce65762529067173c289df5bd](https://github.com/svend4/infod10/commit/c319e43f57da289ce65762529067173c289df5bd) относится к версии 0.23.0 и двадцати пяти предыдущим частям архива.

## Воспроизведение

Из корня репозитория:

~~~sh
python3 scripts/build_session_archive.py --session docs/sessions/session-026 --check
python3 scripts/build_session_archive.py --all --check
~~~

Для намеренной пересборки этой части уберите --check в первой команде. Скрипт не обращается в сеть. Контрольные суммы проверяют сохранённый снимок и не удостоверяют экспорт платформы.
