<a id="m0002"></a>
### m0002 · Ассистент · промежуточное сообщение

Следующий этап будет координировать выбор позиции каталога: один локальный журнал аренды, явный исполнитель, срок и поколение назначения. Одновременные запросы к одной позиции получат одного владельца; после освобождения новое назначение получит следующее поколение.

Аренда будет действовать только внутри этого журнала. Прежний `step` не проверяет её, поэтому она пока не обеспечивает исключительное выполнение задания. Повтор запроса вернёт сохранённую квитанцию без продления срока.

Прикладной запуск проверит обычную конкуренцию, новое поколение после release, восстановление отброшенного ответа и работу без восьми исходных путей. Истечение срока, перевод часов и исчерпание журнала этим запуском воспроизводиться не будут.
