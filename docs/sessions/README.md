# Архивы сессий

Три последовательные части одной доступной беседы: **49 сообщений**. Идентификаторы сообщений локальны для каждой части. Точная граница снимка указана в её описании.

| Сессия | Содержание | Форматы |
|---|---|---|
| [session-001](session-001/README.md) | Настройка среды, интернет, новости ИИ, Scion, аналоги, многoагентные вики и протокол публикации | [Markdown](session-001/transcript.md), [JSONL](session-001/transcript.jsonl), [метаданные](session-001/metadata.json), [контрольные суммы](session-001/manifest.json) |
| [session-002](session-002/README.md) | Сохранение первого снимка, локальный коммит, публикация и проверка GitHub, следующий запрос продолжения | [Markdown](session-002/transcript.md), [JSONL](session-002/transcript.jsonl), [метаданные](session-002/metadata.json), [контрольные суммы](session-002/manifest.json) |
| [session-003](session-003/README.md) | Продолжение архива, проверка публикации и поручение анализа с практической реализацией | [Markdown](session-003/transcript.md), [JSONL](session-003/transcript.jsonl), [метаданные](session-003/metadata.json), [контрольные суммы](session-003/manifest.json) |

Количество сообщений: session-001 — 34, session-002 — 10, session-003 — 5. Первые два снимка сохранены без изменений; каждая следующая часть начинается со следующего сообщения ассистента.

Указатели ссылок из сообщений: [session-001](session-001/links.json), [session-002](session-002/links.json), [session-003](session-003/links.json). Указатель фиксирует присутствие URL в переписке и не заменяет проверку источника.

Тематическая переработка материалов находится в [базе знаний](../knowledge/README.md). Она дополняет исходную переписку.
