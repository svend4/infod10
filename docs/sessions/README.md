# Архивы сессий

Две последовательные части одной доступной беседы: **44 сообщения**. Идентификаторы сообщений локальны для каждой части. Точная граница снимка указана в её описании.

| Сессия | Содержание | Форматы |
|---|---|---|
| [session-001](session-001/README.md) | Настройка среды, интернет, новости ИИ, Scion, аналоги, многoагентные вики и протокол публикации | [Markdown](session-001/transcript.md), [JSONL](session-001/transcript.jsonl), [метаданные](session-001/metadata.json), [контрольные суммы](session-001/manifest.json) |
| [session-002](session-002/README.md) | Сохранение первого снимка, локальный коммит, публикация и проверка GitHub, следующий запрос продолжения | [Markdown](session-002/transcript.md), [JSONL](session-002/transcript.jsonl), [метаданные](session-002/metadata.json), [контрольные суммы](session-002/manifest.json) |

Количество сообщений: session-001 — 34, session-002 — 10. Исходный первый снимок сохранён без изменений; продолжение начинается со следующего сообщения ассистента.

Указатели ссылок из сообщений: [session-001](session-001/links.json), [session-002](session-002/links.json). Указатель фиксирует присутствие URL в переписке и не заменяет проверку источника.

Тематическая переработка материалов находится в [базе знаний](../knowledge/README.md). Она дополняет исходную переписку.
