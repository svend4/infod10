# Обязательная проверка содержания — session-017

Продолжение [session-016](../session-016/README.md): пояснения об обязательной проверке объявленных связей документации и кода, выполненном сценарии и публикации версии 0.14.0, итоговый ответ, затем запрос пользователя «Продолжение».

Сохранено **9 сообщений**: 1 пользователя и 8 ассистента, из них 7 промежуточных пояснений и 1 итоговый ответ. Вместе с шестнадцатью предыдущими частями — **154 сообщения**. Идентификаторы m0001–m0009 назначены локально и относятся только к этой части.

## Границы и точность

Это ручной перенос доступного контекста беседы, а не экспорт платформы. Содержание доступных сообщений сохранено без исправлений. Служебные инструкции, внутренние рассуждения, сообщения субагентов и необработанные результаты инструментов в архив не входят. Время отдельных сообщений недоступно; поля timestamp имеют значение null.

Граница снимка — запрос пользователя «Продолжение» после публикации версии 0.14.0 включительно. Последующие анализ, разработка и ответы об этой работе в данный снимок не входят. Предыдущие части архива не изменены.

В m0008 сохранён исторический результат проверки публикации: 616 файлов совпали с локальной копией на момент той проверки. Это не результат проверки новых файлов или последующей реализации. Указанный там коммит [9833a4fb46caf7ca7049c895d3b396da4d098226](https://github.com/svend4/infod10/commit/9833a4fb46caf7ca7049c895d3b396da4d098226) относится к версии 0.14.0 и шестнадцати предыдущим частям архива.

## Воспроизведение

Из корня репозитория:

~~~sh
python3 scripts/build_session_archive.py --session docs/sessions/session-017 --check
python3 scripts/build_session_archive.py --all --check
~~~

Для намеренной пересборки этой части уберите --check в первой команде. Скрипт не обращается в сеть. Контрольные суммы проверяют сохранённый снимок и не удостоверяют экспорт платформы.
