# Явный каталог случаев восстановления

Двадцать девятый этап продолжает [учёт заблокированных заданий](../workspace-restore-cases/README.md). Отдельный частный каталог фиксирует явно выбранный состав случаев; страницы наблюдают текущие управляющие записи, сохраняя исторические квитанции.

## Запуск

Из корня существующего checkout укажите новый каталог:

~~~sh
python3 -m agentwiki workspace-restore-case-catalog-demo \
  --workspace /tmp/agentwiki-restore-case-catalog-01 --workers 3
~~~

Состав и порядок остаются фиксированными. Изменённый либо недоступный case path сохраняется отдельной строкой с исторической квитанцией и ограниченной ошибкой. Доступность case metadata не подтверждает состояние старого evidence или нового job: они читаются отдельно через `workspace-restore-case show`.

## Фактический результат

Запуск завершился с первой попытки 21 октября 2026 года в 19:56:23 Europe/Berlin. Сохранены 305 публичных файлов: 294 JSON и 11 Markdown. Из них 287 повторяют основание предыдущего сценария; 18 добавлены этим этапом.

- Первый каталог сохранил три случая в явном порядке и вернул страницы 2 + 1, затем пустую конечную страницу. Отброшенная квитанция создания восстановлена точным повтором.
- Поздний четвёртый случай остался вне первого состава. Второй каталог явно включил его и позже показал связь с уже завершённой попыткой; новых restore jobs не создавалось.
- Исчезнувший путь получил `unavailable`, другая case directory на закреплённом пути — `changed`. Исторические строки сохранились; пути возвращены в finally.
- При временном отсутствии трёх связанных job-каталогов и source bundle страницы оставались доступными. Отдельный show сообщил недоступность текущей попытки и сохранность старого evidence.
- Выполнены 44 новых CLI: 30 успешных и 14 ожидаемо отказавших; сохранены 18 страниц. Составной сценарий включает 230 обычных CLI и 14 workers прежнего основания, всего 244 различных процесса.

Старые заблокированные jobs не перемещались и сохранились неизменными. Исторический источник остался R4/36 событий, действующая среда — R5/59. Время case directories изменялось при rename и не включалось в сравнение static identity; их управляющие файлы сохранили полную наблюдавшуюся identity.
