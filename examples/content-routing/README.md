# Политики разделов и пересечения комплектов

Обычный прикладной сценарий пятнадцатого этапа. Каталог именованных политик выбирает все разделы по реальным writes, затем расширяет выбор через пересечения общих файлов. Данные вымышлены; все роли запрограммированы локально.

## Запуск

Из корня существующего checkout; нужны Python 3.10+ и стандартная библиотека:

~~~sh
python3 -m agentwiki routing-demo --workspace /tmp/agentwiki-routing-my-run-01 --workers 3
~~~

Укажите новый пустой каталог. SQLite и credential-файлы сохраняются в `private/`; CLI использует `--workspace /tmp/agentwiki-routing-my-run-01/private`. Верхние JSON/Markdown-файлы экспортируются отдельно после проверки отсутствия секретов. `private/` не публикуется.

Цепочка A–B–C связана общим кодом и общим документом. Одна запись документа A выбрала только A напрямую, затем замыкание добавило B и C. Комплект только A оказался неполным. Успех A не разрешил вариант, где B и C расходились по значению. Непокрытый файл заблокировал как отдельное предложение, так и смешанную правку с подходящим D.

D не пересекается с A/B/C. Обе правки получили одобрения до первого принятия. После принятия D на ревизии 2 пакет A/B/C и его действующие одобрения сохранились. Правка A/B/C, подготовленная на ревизии 1, принята на ревизии 3 без повторного голосования.

Ранее в том же сценарии D рассматривался под политикой schema 1. После перехода к каталогу schema 2 прежние мнения остались историей и потребовались новые, но старое тело пакета продолжило читаться без изменений. Повторяющиеся локальные ID обязательств и обещаний остаются внутри каждого раздела.

Это показывает консервативность общего каталога: даже правка только D меняет пакет A/B/C; сохранение голосов при таком административном изменении пока отсутствует.

## Границы

Маршрут охватывает объявленные файлы и связи. Полнота описи, истинность прозы, смысловой перевод в поля, поведение программы и независимость участников не установлены. Общий файл может соединить много разделов в крупный обязательный комплект; меньшая конфликтность и ускорение требуют измерения на реальной нагрузке.

SQLite, административная политика и часы доверенные. Локальный bearer подтверждает допуск, без удостоверения человека или модели. Предлагаемый код не исполняется, внешние LLM и человеческая экспертиза отсутствуют. Программа тестирования и измерения нагрузки не запускались. Три workers — размер пула, без измеренной ёмкости портала. Внешняя публикация и выпуск выполняются отдельными действиями.
