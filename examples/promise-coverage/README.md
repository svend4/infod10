# Покрытие заявленных обещаний документации

[Руководство и анализ](../../docs/development/promise-coverage.md) описывают восьмой этап. Опись связывает точную цитату документа с ожидаемым отношением между полем документа и константой кода. Анализ использует один сохранённый отчёт обязательств и не обращается к живой базе.

## Запуск

Из корня репозитория, Python 3.10+ и стандартная библиотека:

~~~sh
python3 -m agentwiki coverage-demo --workspace /tmp/agentwiki-coverage-my-run-01 --workers 3
~~~

Нужен новый пустой каталог. Авторские и редакторские задания запрограммированы, источники вымышлены. Внешние LLM не вызываются, предложенный код не выполняется, человеческое заключение не имитируется. Рабочие SQLite-файлы остаются вне Git.

Сохранённые [отчёт](results/report.md) и [машинный отчёт](results/report.json) относятся к одному выполненному запуску. Новые запуски сохраняйте отдельно от опубликованных результатов.

В сценарии сохранены 3 исходных предложения, 2 композиции, 3 комплекта рассмотрения, 4 анализа обязательств и 5 анализов покрытия двух обещаний. Журнал содержит 3 пакета, 6 решений и 14 событий. Дополнительно выполнены CLI [анализа неполного покрытия](results/cli-analyze-partial.json), [записи нового отчёта](results/cli-partial-coverage.json) и [чтения полного покрытия](results/cli-show-full.json).

## Собственная опись

Для каждого обещания задаются ID, описание, точная цитата, ожидаемое отношение с обоими селекторами, типом и областью, а также список привязанных обязательств. Формат приведён в [руководстве](../../docs/development/promise-coverage.md).

Пустой список `obligation_ids` оставляет обещание непокрытым. Существующий ID не засчитывается автоматически: его фактические метаданные должны совпадать с ожидаемыми. Неоднозначная цитата или неразрешимое поле также требуют рассмотрения.

Для команд ниже задайте `COVERAGE_OBLIGATIONS`, `COVERAGE_INVENTORY` и новый `COVERAGE_REPORT` своими путями:

~~~sh
python3 -m agentwiki coverage analyze --obligations "$COVERAGE_OBLIGATIONS" --input "$COVERAGE_INVENTORY" --output "$COVERAGE_REPORT"
python3 -m agentwiki coverage show --input "$COVERAGE_REPORT"
~~~

Отчёт сохраняется без перезаписи. Для нового анализа создайте новый файл; исторический снимок сохраняет прежние основания.

## Границы подсчёта

Знаменатель — обещания, которые автор включил в опись. Полнота всей страницы не установлена; пропущенные в описи условия не обнаруживаются автоматически. Пустая опись имеет нулевой знаменатель и блокирующую причину, а не 100%.

Покрытие показывает наличие корректных привязок. Выполнение отношений, исходные замечания и актуальность показываются отдельно. Даже при полном покрытии общий результат может оставаться `blocked`. Все результаты требуют рассмотрения человеком: `auto_accept=false`, `live_state_checked=false`.
