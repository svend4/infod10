# Досье предложений документов и кода

Пятый этап соединяет runtime-предложение и редакторский пакет в самостоятельном неизменяемом снимке. [Разбор архитектуры](../../docs/development/proposal-dossiers.md) объясняет границы этой связи.

## Запуск

Из корня репозитория, Python 3.10+ и стандартная библиотека:

~~~sh
python3 -m agentwiki dossier-demo --workspace /tmp/agentwiki-dossier-my-run-01 --workers 3
~~~

Нужен новый пустой каталог. Программные авторы готовят предложения для существующего документа и файла Python. Программные проверяющие записывают решения о соответствующих пакетах. Внешние LLM не вызываются; предложенный код не исполняется.

Демонстрация сохраняет исходные пары, досье, повторные оценки и снимок журнала. SQLite-базы остаются в рабочем каталоге вне Git. Сохранённый [отчёт](results/report.md) и [машинный отчёт](results/report.json) относятся к одному выполненному запуску.

В этом запуске сохранены 2 досье, 2 пакета, 5 решений и 11 событий. Дополнительно выполнены команды CLI после изменения зависимости: [создание досье кода](results/cli-create-code.json), [само созданное досье](results/code-dossier-cli.json) и [повторная оценка документа](results/cli-recheck-document.json). Обе команды отразили `blocked`: новый файл досье не устраняет устаревший `readset` предложения.

## Собственное рассмотрение

В рабочей базе должны уже существовать proposal и исходный артефакт типа document или code. В редакторском журнале должен существовать пакет. Для точной текстовой связи:

- `before.text` равен текущему исходному `template`;
- `after.text` равен предлагаемому `template`;
- текущая пара передаётся явно и загружается один раз.

Для команд ниже задайте `DOSSIER_WORKSPACE`, `DOSSIER_JOURNAL`, `PROPOSAL_ID`, `PACKET_ID`, `ARTIFACT_ID`, `PAIR_FILE` и новый `DOSSIER_FILE` своими значениями:

~~~sh
python3 -m agentwiki dossier create --workspace "$DOSSIER_WORKSPACE" --journal "$DOSSIER_JOURNAL" --proposal "$PROPOSAL_ID" --packet "$PACKET_ID" --artifact "$ARTIFACT_ID" --current-input "$PAIR_FILE" --output "$DOSSIER_FILE"
python3 -m agentwiki dossier recheck --workspace "$DOSSIER_WORKSPACE" --journal "$DOSSIER_JOURNAL" --input "$DOSSIER_FILE" --current-input "$PAIR_FILE"
~~~

Создание не перезаписывает существующий файл. Повторная оценка выводит новое наблюдение, сохраняя исходное досье.

## Что означает результат

`current_for_human_review` означает, что сохранённые основания подходят для дальнейшего рассмотрения человеком. Это не разрешение публикации. `needs_refresh` показывает изменение существенного основания или последних решений; `blocked` — препятствия в текущем наблюдении.

Сопоставляются точные строки шаблонов. Структурированные значения, условия и тип утверждения заданы автором; их соответствие смыслу текста не установлено автоматически. Полнота списка покрытых writes не является полнотой смысловой проверки.

Снимки runtime и журнала получены последовательно. Между ними нет общей транзакции. Согласие агентов, самозаявленный тип `human` и контрольные суммы не предоставляют права `Store.accept`. Досье всегда сохраняет `requires_human_review=true` и `auto_accept=false`.
