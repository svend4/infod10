# Рассмотрение плана и отдельная актуальность основания

Тридцать первый этап продолжает [сохранённые планы удержания](../workspace-restore-case-retention/README.md). Неизменяемая review record сохраняет весь исторический план и самозаявленный verdict. Отдельный revalidate наблюдает текущее основание и вычисляет новые причины по прежней политике.

## Запуск

Из корня существующего checkout укажите новый каталог:

~~~sh
python3 -m agentwiki workspace-restore-case-retention-review-demo \
  --workspace /tmp/agentwiki-restore-case-retention-review-01 --workers 3
~~~

Дополнительные пакеты и внешние модели не требуются. Сценарий повторяет прежнее основание и сохраняет новые результаты отдельно от прошлых примеров.

## Фактический результат

Сценарий завершился с первой попытки 21 октября 2026 года в 22:55:13 Europe/Berlin. Сохранён 341 публичный файл: 328 JSON и 13 Markdown. Из них 323 повторяют основание прежнего сценария; 18 добавлены этим этапом.

Сохранены два рассмотрения и 15 отдельных перепроверок. Первое рассмотрение фиксирует `reviewed` для нулевого срока: две строки остаются held из-за неизвестной исходной identity, хотя наблюдаемое основание совпадает. Второе фиксирует `request_fresh_plan` для плана с ранее недоступной попыткой: после её возврата текущая строка становится кандидатом, но историческое основание не получает подтверждения задним числом.

| Новое наблюдение | Результат |
| --- | --- |
| Попытка или case недоступны | Текущая строка held, сравнения ложны |
| Plan либо catalog недоступны | Binding unavailable; сохранённые cases всё ещё наблюдаются |
| На пути plan другой существующий каталог | Binding changed до разбора его controls |
| Все 14 live paths недоступны | Исторические show/replay доступны; отдельная revalidation сообщает недоступность |
| Исходные пути возвращены | Наблюдения minimum снова совпадают; исторические записи прежние |

Настоящий успешный ответ record отброшен и восстановлен точным повтором. Все временные переименования отменены в finally; старые blocked jobs никогда не перемещались. Сохранность controls сравнивалась по полной файловой metadata и static directory identity без времён каталогов, меняющихся при rename.

Выполнены 45 новых обычных CLI: 34 успешных и 11 ожидаемых отказов. С прежним основанием это 313 CLI и 14 унаследованных interrupt workers, всего 327 различных процессов; новых прерываний нет. Source/живая история сохранили R4/36 событий и R5/59. Доменные записи, новые attempts, grants, credentials, архивирование и удаление сверх повторённого основания не выполнялись.

Независимые read-only сверки подтвердили строгие публичные схемы и 319 ссылок отчётов, точную частную реконструкцию исходных планов, pins и права 0700/0600, неизменность данных и истории. Отдельный публичный обзор выполнил 31805 логических сравнений и 341 побайтное сравнение экспортов. Privacy-сверка сохранила 3269 прежних защищённых файлов и не обнаружила известных credentials, их хешей и частных привязок в 3754 кандидатах публикации.
