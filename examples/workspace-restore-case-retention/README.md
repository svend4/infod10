# Сохраняемый план удержания случаев

Тридцатый этап продолжает [каталог случаев](../workspace-restore-case-catalog/README.md). Отдельный частный план сохраняет выбранный диапазон, срок удержания, один момент оценки и подробные наблюдения, объясняющие `held` либо `review_candidate`.

## Запуск

Из корня существующего checkout укажите новый каталог:

~~~sh
python3 -m agentwiki workspace-restore-case-retention-demo \
  --workspace /tmp/agentwiki-restore-case-retention-01 --workers 3
~~~

Возраст отсчитывается от case.created_at. Неизвестная исходная identity остаётся неизвестной; недоступные либо изменённые свидетельства сохраняются как причины удержания. Точный replay и show возвращают прежний снимок независимо от текущей доступности источников.

## Фактический результат

Запуск завершился с первой попытки 21 октября 2026 года в 20:52:38 Europe/Berlin. Сохранены 323 публичных файла: 311 JSON и 12 Markdown. Из них 305 повторяют основание предыдущего сценария; 18 добавлены этим этапом.

| План | Кандидаты для рассмотрения | Удержанные случаи |
| --- | --- | --- |
| Нулевой срок | 2 | 2: неизвестная исходная identity |
| Срок 315360000 секунд | 0 | 4: срок не истёк; у двух также неизвестна identity |
| Недоступный известный case | 1 | 3: две неизвестные identity и один case_unavailable |
| Недоступная связанная попытка | 1 | 3: две неизвестные identity и один attempt_unavailable |

Отброшенный успешный ответ plan восстановлен точным повтором. После возврата отсутствующих путей сохранённые причины остались прежними. При временно скрытых двух каталогах, четырёх случаях, трёх job-каталогах и source bundle все четыре show и точный replay оставались доступны; пути возвращены в finally.

Выполнены 38 новых CLI: 23 успешных и 15 ожидаемо отказавших. Составной сценарий включает 268 обычных CLI и 14 workers прежнего основания, всего 282 различных процесса. Новых прерываний нет. Source/живая история сохранили R4/36 событий и R5/59; исходные blocked jobs не перемещались. Сравнение управляющих файлов включало полную lstat identity, сравнение каталогов — static identity без изменяемых при rename времён.
