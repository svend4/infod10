# Разбор изменений требований после пересмотра

Сценарий продолжает [явный пересмотр описи](../inventory-amendment/README.md). Он читает пять закреплённых отчётов прошлых этапов, создаёт пять новых авторских планов и анализирует семь amendment-отчётов. Два из них импортированы без изменения. Runtime и редакторский журнал не открываются.

## Запуск

Из корня существующего checkout в новом пустом каталоге:

~~~sh
python3 -m agentwiki requirement-delta-demo \
  --workspace /tmp/agentwiki-delta-my-run-01 --workers 3
~~~

Сохранён фактический запуск `/tmp/infod10-requirement-delta-development-01`: [отчёт](results/report.md), [JSON](results/report.json). Каталог `results` содержит 22 прикладных файла и четыре файла трёх дополнительных CLI-вызовов.

## Что наблюдалось

| Случай | Изменение | Состояние |
|---|---|---|
| Новая цитата | Требование и выбранные значения прежние; изменён текст | `current_for_human_review` |
| Равенство → включение | Ослаблена схема объявленного предиката | `current_for_human_review` |
| Включение → равенство | Усилена схема объявленного предиката | `current_for_human_review` |
| Новая метка scope | Структурное изменение без направления следования | `current_for_human_review` |
| Лимит 3 → 4 | Изменены значения, отношение равенства прежнее | `current_for_human_review` |
| Неверная единица | Сохранились исходные препятствия привязки | `blocked` |
| Повтор при stale основании | Покрытие восстановлено, устаревание осталось действующим | `blocked` |

Во всех случаях сохранены два исходных ID и порядок. Пять отчётов готовы к рассмотрению человеком, два заблокированы. Это не новые решения редактора и не принятые файлы.

В случае [ослабленного отношения](results/relation-relaxed-delta.json) новая опись имеет покрытие 2/2, выбранные множества не изменились и оба отношения дают `match`. Замена правила всё же выделяется как `declared_relation_relaxed`. Вывод относится к схеме C = D → C ⊆ D над произвольными конечными наборами. Фактическое изменение поведения программы не устанавливается.

В [числовом сценарии](results/fictional-attempt-limit-delta.json) документ и код согласованно меняют лимит с 3 на 4. Инструмент показывает изменение выбранных значений, сохраняя неустановленное направление гарантии для читателя.

## Основания

[source-import.json](results/source-import.json) фиксирует SHA256, размеры, ID и URL пяти входов на коммите `dd5f63b0bef5ded8f0a4b3a5f55475b70241d1a9`. Байты сверены с закреплёнными значениями; загрузчики проверяют внутренние отчёты.

Материал ручного адаптера urllib3:

- [Исходное покрытие](../inventory-amendment/results/base-coverage.json).
- [Пересмотр цитаты](../inventory-amendment/results/revised-quote-amendment.json).
- [Неверная единица](../inventory-amendment/results/wrong-unit-amendment.json).

Отдельные вымышленные основания:

- [Изменение лимита попыток](../inventory-rebase/results/changed-rebase.json).
- [Изменение зависимого тайм-аута](../inventory-rebase/results/stale-rebase.json).

Числовой сценарий не относится к `Retry.total` и не описывает изменение urllib3. В сценариях адаптера меняются авторские требования к сохранённому кандидату; исходная библиотека и её документация не обновляются.

Каждый новый анализ включает полный amendment и цепочку его оснований. Старые snapshots остаются отдельными файлами без изменения. Повторное чтение исторического редакторского решения не становится новым независимым голосом.

## Отдельные CLI-вызовы

~~~sh
python3 -m agentwiki requirement-delta analyze \
  --amendment examples/requirement-delta/results/relation-relaxed-amendment.json \
  --output /tmp/agentwiki-relaxed-delta-01.json

python3 -m agentwiki requirement-delta show \
  --input /tmp/agentwiki-relaxed-delta-01.json

python3 -m agentwiki requirement-delta show \
  --input examples/requirement-delta/results/stale-reaffirm-delta.json
~~~

Для сохранённого CLI-анализа использован новый путь `results/cli-relation-relaxed-delta.json`. Ответы: [analyze](results/cli-analyze-relaxed.json), [show нового анализа](results/cli-show-relaxed.json), [show устаревшего основания](results/cli-show-stale.json). Последний сохранил `blocked`, внимание по двум записям и все исходные препятствия.

## Границы результата

Семь заданий выполнены в трёх наблюдавшихся Python-потоках анализа. Новые предложения файлов, редакторские решения, принятие, выпуск и вызовы внешних LLM отсутствуют. Предложенный код не исполняется, живая база не проверяется.

Внимание редактора отделено от действующих препятствий и не является новой политикой принятия. Смысловая эквивалентность прозы, полнота описи, направление предметной гарантии, качество и выигрыш времени не установлены. [Подробный анализ](../../docs/development/requirement-delta.md) объясняет поддерживаемую алгебру и следующие шаги.
