# Одна фаза записи с проверкой текущей аренды

[Протокол и анализ](../../docs/development/workspace-restore-case-retention-review-write-action.md) · [читаемый отчёт](results/restore-case-retention-review-write-action-report.md) · [машинный отчёт](results/restore-case-retention-review-write-action-report.json).

~~~sh
python3 -m agentwiki workspace-restore-case-retention-review-write-action-demo \
  --workspace /tmp/agentwiki-review-write-action-01 --workers 3
~~~

Сценарий готовит отдельный новый write job, явный каталог и локальный ledger. Сохранённое действие закрепляет только один переход prepared→ready, ready→linked либо linked→completed. Текущая аренда проверяется перед новым исполнением; запись готового результата позволяет повторять ответ без нового шага.

Два callers одного action должны получить одинаковый результат. Другое действие, уже наблюдающее точный POST, сохраняет отдельное наблюдение без эффекта и заявления о причине. Устаревшая аренда и слишком поздняя фаза блокируют новый шаг. Исторический результат читается отдельно от текущих путей и не продлевает назначение.

Worker самозаявленный. Прежний прямой step не требует этого action, другие ledgers независимы. Здесь не измеряются предельное число LLM, throughput, полнота либо истинность документации. Private controls, pins, SQLite и credentials находятся вне публикации.

## Выполненный запуск

Development-запуск завершён с первой попытки 22 октября 2026 года в 17:19:06 Europe/Berlin. Экспортированы 413 файлов: 396 JSON и 17 Markdown, включая 395 файлов прежнего основания. Новые 74 CLI дали 55 успешных ответов и 19 ожидаемых отказов; 45 из них — action commands, 29 успешных и 16 отказов.

Шесть намерений сохранили четыре результата: три выполненные фазы и одно наблюдение без эффекта. Два остальных намерения остались без результата после отказов stale generation и beyond-target phase. Четыре события нового ledger не изменялись выполнением действий; два callers одного action получили одну сохранённую квитанцию.

Всего с основанием 587 ordinary CLI и 14 прежних interrupt workers, 601 различный PID. Перекрытие исполнения и ёмкость пула не измерялись. Первичная private-сверка проверила новый review, pinned inode, все action records и SQL history без изменения bytes/metadata либо ремонта. Initial Store setup предшествует baseline-снимку старых controls.

Все восемь завершающих read-only сверок прошли с первой попытки. Два публичных обзора вместе выполнили 170197 логических и 413 побайтных сравнений, согласовав весь экспорт. Schema-аудит подтвердил 391 относительную ссылку результатов и 601 различный PID. Preservation сохранил 4769 прежних защищённых файлов; в 5342 кандидатах не обнаружены проверяемые private credentials и контрольные суммы. Подробные основания, границы и результаты находятся в руководстве и журнале работ.
