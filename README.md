- [Та же переписка — JSONL](docs/sessions/session-001/transcript.jsonl).

Исходные сообщения сохранены отдельно от конспекта. Предложенная в разговоре архитектура не означает, что приложение уже реализовано. Результаты проверок среды относятся к моменту соответствующего сообщения.

## Содержимое

| Путь | Назначение |
|---|---|
| docs/sessions/ | Архивы переписки, метаданные и контрольные суммы |
| docs/knowledge/ | Тематические материалы со статусами утверждений и источниками |
| scripts/build_session_archive.py | Воспроизводимая сборка Markdown и манифеста из JSONL |
| AGENTS.md | Правила дальнейшего ведения репозитория |

## Проверить архив

Из корня репозитория:

~~~sh
python3 scripts/build_session_archive.py --check
~~~

Для повторной сборки производных файлов после намеренного изменения JSONL:

~~~sh
python3 scripts/build_session_archive.py
~~~

Скрипт использует только стандартную библиотеку Python и не обращается в сеть.
