# Описание Jupyter блокнотов

### `_untitled3_ipynb.ipynb`
Этот блокнот содержит интерактивные шаблоны для анализа данных, визуализации, обучения моделей классификации и кластеризации. В нём можно генерировать синтетические данные и создавать тестовые документы (HTML, JSON, CSV).
**Используемые библиотеки:** google, json, matplotlib, numpy, os, pandas, plotly, seaborn, sklearn.
