# Авторская учебная опись выбранных объявлений Retry 2.5.0

Этот документ составлен ИИ-авторами проекта по закреплённому исходнику;
он не опубликован командой urllib3 и не является экспертной разметкой.
Файл contract-misstated-total-unit.md — намеренно неверная авторская
иллюстрация единицы total при неизменном числовом JSON. Совпадение полей
и точная цитата не подтверждают смысл свободного текста.

Набор Retry.DEFAULT_ALLOWED_METHODS содержит HEAD, GET, PUT, DELETE, OPTIONS и TRACE; POST в нём отсутствует.

У конструктора Retry значение total по умолчанию равно 10; параметр считает повторы, а не все попытки.

Набор Retry.DEFAULT_REMOVE_HEADERS_ON_REDIRECT содержит Cookie, Authorization и Proxy-Authorization; это имена в объявлении константы, до преобразования в нижний регистр.

У конструктора Retry выражение по умолчанию для backoff_factor — целочисленный литерал 0, хотя параметр аннотирован как float.

```json agentwiki:retry-defaults
{
  "default_allowed_methods": ["HEAD", "GET", "PUT", "DELETE", "OPTIONS", "TRACE"],
  "total_default": 10,
  "default_remove_headers_on_redirect": ["Cookie", "Authorization", "Proxy-Authorization"],
  "backoff_factor_default": 0
}
```

Область четырёх объявлений задана явно. Набор методов не является
универсальным запретом повторять POST; allowed_methods=None описан в
исходной документации как возможность повторять любой verb при остальных
условиях политики. Выбранные имена заголовков относятся к объявлению
константы, а отдельное выражение h.lower() в конструкторе здесь не исполняется.

Объявление backoff_factor содержит литерал int 0 при аннотации float.
Типы допустимых значений во время исполнения и полное расписание задержек
не выводятся из этой формы. Числа и множества проверяются отдельно от
содержания фраз, единиц и границ применимости.

Четыре исключённых кандидата перечислены в selection-register.json:
integer frozenset, class integer, default Name и float default не выдаются
за поддержанные связи. Восемь записей регистра не образуют исчерпывающую
опись программы или знаменатель полноты всей документации.
