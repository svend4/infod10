# Авторский корпус структурированных смысловых изменений

[Файл cases.jsonl](cases.jsonl) содержит **24 авторские иллюстрации**, подготовленные ИИ-агентами в ходе разработки, для условного API и энциклопедического портала. Проверка разметки экспертом-человеком не проводилась. Задача корпуса — сделать различия и границы формального сравнения доступными для обсуждения при разработке многоагентной системы документов и кода.

Это учебный материал авторов проекта. Он не является экспертным эталоном, независимой разметкой, тестовым набором, бенчмарком или доказательством качества алгоритма. Сценарии не выбирались случайно и не отражают распределение реальных ошибок. Здесь нет метрик точности, сравнений моделей и измерений производительности. Все описанные продукты, авторы и источники вымышлены; упоминания Linux, Windows и macOS относятся к поддержке в условном продукте.

## Что внутри

| Категория | Число | Иллюстрируемые различия |
|---|---:|---|
| units | 5 | Равные единицы, изменение величины, несовместимые размерности, точные десятичные числа, неизвестное обозначение |
| scope | 3 | Разные версии, отсутствующая версия, частичная область действия |
| modality | 2 | Рекомендация становится требованием; разрешение становится запретом |
| polarity | 2 | Отрицание предиката и положительная формальная часть при перефразировании |
| kind | 2 | Измерение становится гарантией; рекомендация получает статус спецификации |
| sets | 4 | Полное и открытое перечисление, перестановка элементов, изменение полноты |
| attribution | 1 | Другой автор того же мнения |
| time | 2 | Изменение даты и явно указанных интервалов действия |
| provenance | 2 | Отсутствующая привязка к источнику и цитата, которой нет в снимке |
| free_text | 1 | Неопределённое обещание скорости и нагрузки |
| **Итого** | **24** | Авторские разборы без оценки качества |

У каждого случая есть до и после, снимки источников, авторский комментарий и ограничения. Случаи с совпадающим формальным значением соседствуют с существенными изменениями и ситуациями, где безопаснее воздержаться от вывода. Такое сочетание помогает объяснять поведение интерфейса, но не измеряет частоту правильных решений.

## Формат записи

Одна строка UTF-8 JSONL — один объект schema_version 1 со следующими полями:

| Поле | Смысл |
|---|---|
| case_id | Уникальный локальный идентификатор из строчных латинских слов через дефис |
| category, title | Тематическая группа и русское название иллюстрации |
| before, after | Два явно структурированных утверждения |
| sources | Словарь локальных вымышленных снимков с текстом и SHA-256 его точных байтов UTF-8 |
| annotation | Авторские relation, action, rationale и статус project_authored_illustration |
| limitations | Ограничения конкретного сценария и его интерпретации |

Утверждение содержит subject, property, scope, kind, modality, polarity, value, attribution, evidence и text. Поля вводятся автором: программа не извлекает автоматически версию, отрицание, обязательность или авторство из русского текста. Область scope — словарь строк; пустая область и удаление поля региона намеренно представлены как неоднозначные случаи. Разные области нельзя автоматически считать непересекающимися.

Поддерживаются формы value:

- quantity: amount как **десятичная строка**, unit как обозначение единицы. Числа JSON с плавающей точкой в значениях количества не используются.
- set: уникальные строки members и булев флаг complete. Порядок элементов не является смыслом множества; для последовательностей нужна другая модель.
- boolean: булево value.
- date: календарная строка value в формате YYYY-MM-DD.
- text: непрозрачная строка text, не числовое измерение и не автоматически распознанная логика.

Словарь единиц включает ms, s, min, h; B, KiB, MiB; count и percent. Обозначение «сек» в одном случае намеренно оставлено вне словаря. В примере точности сравниваются десятичные строки 0.000000000000000001 s и 0.000000000000001 ms; возможность реализовать такой таймер не утверждается.

## Как читать авторскую аннотацию

Annotation — пояснение замысла автора корпуса. Поля relation и action содержат описательные обозначения, а не обязательный ответ программы. Их словарь может отличаться от имен отношений и действий анализатора. Например, quantity_equivalent относится к формальному числу и единице; action inspect_rendering предлагает посмотреть оформление, но не одобряет источник, весь текст или публикацию.

Авторская аннотация отображается рядом с результатом и **не поступает на вход функции сравнения**. Совпадение с ней не означает правильность, а различие не объявляется автоматически ошибкой. Для независимой оценки потребуются отдельная спецификация решений, независимые разметчики, разбор разногласий и отложенные данные; эти работы ещё не выполнены.

В четырёх иллюстрациях с неизменной формальной частью — равные единицы, точные десятичные величины, перестановка множества и положительное перефразирование — обе стороны используют один снимок и одну цитату, явно поддерживающую оба представления. Это помогает отдельно рассмотреть изменение представления. В остальных случаях снимки before и after часто различаются: меняются байты текста, цитата и контрольная сумма. Формальная эквивалентность сама по себе не означает неизменность происхождения; анализ происхождения следует читать отдельно от численного отношения.

## Что означает источник

Каждый текст источника начинается пометкой «ВЫМЫШЛЕННЫЙ ИСТОЧНИК». SHA-256 связывает запись с точными байтами снимка. Evidence хранит source_id, source_digest и дословную цитату quote. Наличие цитаты показывает только присутствие строки в указанном снимке; это не проверка достоверности автора, истинности утверждения или логической достаточности цитаты.

Есть два намеренных проблемных случая:

- provenance-missing-evidence: снимок after сохранён в sources, но поле after.evidence равно null. Его нельзя незаметно восстановить по совпадению текста.
- provenance-quote-not-in-source: SHA-256 снимка верен, но цитата after отсутствует в нём. Это единственное намеренное исключение из обычного требования точного вхождения цитаты; случай нужен для явного отказа от подтверждения основания.

Имена источников локальны случаю. Наличие двух снимков не означает двух независимых свидетельств. Время действия утверждения в scope не заменяет время публикации, получения или проверки источника.

## Работа через CLI

Команды запускаются из корня checkout репозитория. Они читают локальные данные и не подключают внешние LLM. Пример просмотра и разбора одного случая:

~~~bash
python3 -m agentwiki corpus list
python3 -m agentwiki corpus show --case units-equivalent-seconds-milliseconds
python3 -m agentwiki corpus analyze --case units-equivalent-seconds-milliseconds
~~~

Вариант show --pair выдаёт только before, after и sources, без аннотации автора. Его можно сохранить и передать в отдельный разбор:

~~~bash
python3 -m agentwiki corpus show --case units-equivalent-seconds-milliseconds --pair > /tmp/my-statement-pair.json
python3 -m agentwiki review-pair --input /tmp/my-statement-pair.json
~~~

Для собственного материала подготовьте JSON-объект с теми же полями before, after и sources по описанной схеме, без авторской annotation, и передайте путь:

~~~bash
python3 -m agentwiki review-pair --input /tmp/my-statement-pair.json
~~~

Разбор не является разрешением на принятие или публикацию правки. Он не меняет каноническое состояние SQLite, не запускает предложенный программный код и не проверяет произвольные программы. Подробные границы и следующий этап развития описаны в [руководстве этапа](../../docs/development/semantic-corpus.md).

## Дальнейшее пополнение

Новые авторские случаи следует добавлять с явной пометкой происхождения, корректными контрольными суммами и отдельным объяснением неоднозначности. Не исправляйте иллюстрацию только ради совпадения с текущим выводом программы. Изменение явно заданных полей требует редакционного рассмотрения, поскольку оно меняет поставленный вопрос.

Для будущего исследования потребуются реальные разрешённые материалы, сравнение с простыми базовыми правилами, независимая разметка и отдельные данные оценки. Расширение этого иллюстративного корпуса само по себе не заменяет ни одну из этих работ.
